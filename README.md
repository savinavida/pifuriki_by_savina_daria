# Пифурики
Текстовый квест о мечтателе и фаталисте Рохо. Он грезит о богемной жизни, но вынужден зарабатывать на хлеб, помогая популярной гадалке Фифе формулировать предсказания, по которым уже давно живет весь город. Узнав, что Фифе манипулирует горожанами через онлайн-слежку, Рохо сталкивается с главным выбором в жизни: бороться, созидать или властвовать. 
![](pifuriki_by_savina_daria.png)
История Рохо — это интерактивное роуд-муви о самостоятельном поиске своей судьбы в мире, где цифровая клетка кажется свободой, а выход из нее можно найти, сделав свой выбор.
